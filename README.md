# 4-Bit CPU Design Using Logisim

## Project Overview
This project focuses on the design and implementation of a 4-bit Central Processing Unit (CPU) using Logisim.

## Components
- Arithmetic Logic Unit (ALU)
- Registers
- Control Unit
- Data Path
- Other essential CPU components

## Tool Used
- Logisim

## Project File
- `4bit_CPU_design.circ`

## Objective
To understand the basic architecture and working principles of a CPU through digital circuit design and simulation.
